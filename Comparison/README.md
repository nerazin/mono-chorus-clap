# Historical 0.3.0 comparison

`fixed_settings_results.csv` contains the earlier 0.3.0 floating-point
plug-in's measurements. The percentages compare its output against the
isolated firmware chorus at fixed 44.1 kHz settings, using
`100 × (1 − RMS(reference − output) / RMS(reference))`.

These results are retained for context. They do **not** measure version
0.4.0. See the [main README](../README.md#sample-rate-latency-and-accuracy)
for the scope and limitations of the newer tests.
